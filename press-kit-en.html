SpaceWish Press Kit

SpaceWish is a digital experience for creating a personal message package intended for a future confirmed space radio transmission.

One-line description

SpaceWish lets a user write a personal message, select an astronomical destination and create a preliminary digital package with a Universe ID and certificate.

Current MVP status

  • public message builder;
  • Universe ID and preliminary certificate;
  • gift mode;
  • EEG fingerprint concept demo;
  • knowledge base about radio communication, SETI/METI and historic messages sent beyond Earth.

Important factual boundaries

  • No real transmission session should be described as completed until technically confirmed.
  • No specific antenna, frequency, power or date should be described as final before operator confirmation.
  • EEG is not presented as semantic mind reading.
  • SpaceWish does not sell ownership of stars or official naming rights.
  • No extraterrestrial response is promised.

Suggested media description

“SpaceWish is a project for personal digital messages intended for a future space radio transmission. Users create a message, select an astronomical destination and receive a preliminary digital certificate. Actual transmission parameters will be published only after technical confirmation by the operator.”
