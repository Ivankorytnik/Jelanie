# SpaceWish — «Желание сквозь Вселенную»

Official website: https://spacewish.agency/

SpaceWish is a Russian-language digital project for creating personal message packages intended for a future confirmed space radio transmission.

## Current status

The project is currently an MVP. It can create a preliminary digital message package, Universe ID and certificate. A real transmission site, date, frequency, power and antenna must not be treated as confirmed until the technical operator confirms them.

## Factual boundaries

- SpaceWish does not claim that a real transmission has already happened.
- EEG is not presented as semantic mind reading.
- SpaceWish does not sell ownership of stars or official naming rights.
- No extraterrestrial response is promised.

## Knowledge sources

Public educational content references authoritative sources including NASA, JPL, SETI Institute, NIH/NINDS, IAU and ESA.
